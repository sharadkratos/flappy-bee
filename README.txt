FLAPPY BEE — WEB HOSTING PACKAGE

Files:
- index.html       Main game. No external libraries or login required.
- manifest.webmanifest  Optional web-app metadata for supported browsers.

FASTEST FREE DEPLOYMENT: NETLIFY DROP
1. Open https://app.netlify.com/drop
2. Drag this entire folder onto the Drop zone.
3. Netlify gives you a public netlify.app URL.
4. Open that URL in Safari/Chrome on the iPhone.
5. Share the URL through WhatsApp.

ALTERNATIVE: GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html and manifest.webmanifest to the repository root.
3. Enable GitHub Pages from Settings > Pages.
4. Publish from the main branch/root.

IMPORTANT
- Do not open the game from the iPhone Files preview if you want to test JavaScript.
- Use Safari/Chrome with the public URL. The Files preview may display HTML/CSS without running the game reliably.
